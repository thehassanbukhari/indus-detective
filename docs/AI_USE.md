# Use of SI and AI tools in Indus Detective

Indus Detective was built by team GitGoblins for the NASA Space Apps Challenge 2026, Topi local event. This file says where AI tools were used, as the challenge rules ask.

## Summary

Syed Hassan Ali Bukhari led the project and made the decisions. He used Claude, a large language model from Anthropic, through the claude.ai chat as an assistant for planning, research, code and wording. The question, the choice of data, the method, what stayed in and what was cut, and every release were the team's calls. Claude helped carry them out.

## Where Claude helped

| Area | How it helped |
|---|---|
| Ideation | Talked through the challenge, the story and the page order. The team lead made the final choices. |
| Research | Searched for and summarised sources: NASA documentation, GISTEMP, press coverage of the PMD report. Each source is linked on the site and was checked against the page. |
| Code and data | Drafted the Python scripts in lab/ that fetch NASA POWER data and compute the trends, and the React and TypeScript code in web/. The team lead ran the scripts, tested them and committed the code. |
| Writing | Drafted and edited the site text, the README and the project descriptions. The team lead reviewed and revised them. |
| Design | Suggested layout, type and the Concise and Extended views. The team lead approved or rejected each change. |

## How the work was checked

- Every number on the site is read from the data files, not typed into the text.
- The method was tested on synthetic data with a known trend.
- A teammate compared stored values with NASA's own POWER Data Access Viewer for 5 places and 30 values. All matched (docs/HAND_CHECK.md).
- Wrong counts and wording were corrected against the data files during the build.
- The team lead reviewed the modules and can explain them.

## Teammates

The release research teammate used Claude to read project guidance, search for the PMD report, compile the library and licence list, and draft a video script and slide outline. The testing teammate used Claude to prepare a phone test checklist and to check values copied from NASA's viewer. The test results, recordings and stranger answers come from real people.

## What AI did not do

- No image, audio or video in this repository or on the site was generated by AI.
- Nothing uses NASA logos or other NASA branding.
- AI did not create any data. All results come from NASA data processed by the scripts in this repository.

## Disclosure note

The code in lab/ and web/, and the text in README.md, docs/ and on the site, were drafted with Claude and reviewed by the team lead, as described above. The repository is open under the MIT licence, so every line can be inspected.
